# planfiles tap

```sh
brew install planfiles/tap/planfiles
```

Prebuilt, Developer-ID-signed and notarized macOS binaries for
[planfiles](https://planfiles.sh) — your `.plan`, your todos, your devlog:
one plain-text daily page in the terminal.

- The formula lands here with the first release; binaries are attached to
  this repo's [Releases](https://github.com/planfiles/homebrew-tap/releases).
- Prefer curl? `curl -fsSL https://planfiles.sh/install | sh`
- planfiles is proprietary software — using the binaries means agreeing to
  the [EULA](EULA.md). Short version: your `.plan` files stay yours, always.
  The Homebrew recipe itself is MIT — see [LICENSE.md](LICENSE.md).

This repo is publish-only: the formula and release artifacts are pushed by
the planfiles release pipeline. Issues are welcome for install problems.
